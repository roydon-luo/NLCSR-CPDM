# NLCSR-CPDM

This repository contains the implementation of **Learning a Non-Locally Regularized Convolutional Sparse Representation for Joint Chromatic and Polarimetric Demosaicking**.  Two independent implementations are provided:

| Implementation | Entry documentation | Recommended use |
| --- | --- | --- |
| MATLAB | [Matlab/README.md](Matlab/README.md) | Original implementation; real and synthetic demosaicking demos |
| Python | [Python/README.md](Python/README.md) | CPU/CUDA implementation; single- and multi-GPU processing |

Choose one implementation and follow its README.  Each implementation includes its own source code and example inputs, so it can be run independently from its directory.

## Release history

- **2025-03-10** — Original MATLAB implementation released.
- **2026-09-21** — Python implementation released publicly.
